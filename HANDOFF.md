# ЛАЙМ / lime-city-site — передача на доработку

Статический сайт студии ЛАЙМ (внедрение CRM × вайбкодинг). Без сборки и зависимостей: чистый HTML/CSS/JS. Этот файл — вводная для доработки (в т.ч. как контекст для ИИ-ассистента).

## Запуск и деплой

```bash
python3 -m http.server 8077
# открыть http://localhost:8077
```

- Репозиторий: https://github.com/a99584562-commits/lime-city-site
- Прод: **GitHub Pages из ветки `main` (корень)** → https://a99584562-commits.github.io/lime-city-site/
- Любой push в `main` = деплой на прод через ~1–2 мин. Аккуратно с прямыми пушами.

## Архитектурные особенности (важно!)

1. **Вся вёрстка index.html — на инлайн-стилях.** Адаптив сделан единым блоком `@media (max-width:768px)` в `<head>`, который переопределяет инлайн через селекторы-подстроки + `!important`, например `[style*="1fr 1fr"]{grid-template-columns:1fr!important}`.
2. **Грабли матчинга инлайн-стилей:** браузер сериализует `style` с пробелом после двоеточия (`prop: value`). Селектор `[style*="position:sticky"]` НЕ сматчится — матчить только по значению: `[style*="sticky"]`, `[style*="1fr 1fr"]`.
3. **Движок города** — один `<script>` в index.html: изометрия на 2D canvas (`iso()`, TW=36/TH=18), процедурная сцена, достраивается по прогрессу скролла. Глобальная скорость анимаций — `time * 0.5` в `draw()`. Порядок отрисовки: plates → conns → buildings.
4. Хелперы зданий уже есть — **не дублировать**: `wall()`/`winWall()` (грани: градиент, цоколь `baseBand`, карниз `cornice`, световой шов `edgeHi`), `roofShine()` (свет на крышах), `roofShadow()` (посадка верхних ярусов), `castShadow()` (мягкая тень), `depthFade()` (растворение дальних зданий — только на зданиях, НЕ на коннекторах).
5. **Курсор:** тёмные секции помечаются атрибутом `data-cursor-dark` — курсор сам становится светлым. Лейбл курсора — `data-cursor="Текст"`. Новые страницы: просто подключить `<script src="lime-cursor.js" defer>`.
6. **Прелоадер и интро** (`#lime-loader`, `data-intro`) учитывают `prefers-reduced-motion`.
7. В hero и футере буква **«Й» — это «И» + SVG-листок сверху** (`aria-label="Й"`). Поиск по «Й» в разметке её не найдёт.

## Что решено и отвергнуто (НЕ возвращать без согласования с Артёмом)

- Инерционный скролл (Lenis) — отвергнут, только нативный + `scroll-behavior:smooth` для якорей.
- Glow/«кометные следы» на дорогах-коннекторах города, подписи районов на канвасе, жёсткие однослойные тени, тёмная секция-карусель — отвергнуты.
- Telegram/WhatsApp в контактах НЕ использовать — вместо них MAX.
- Дизайн-направление: светлый «бумажный» премиум, лаймовый акцент `#B8E020`, срез угла как мотив. Итерировать поверх этого стиля, не заменять чужой дизайн-системой.
